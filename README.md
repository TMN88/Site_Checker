# Site_Checker для OpenWrt 24.x и 25.x

LuCI-панель для проверки доступности сайтов непосредственно с роутера OpenWrt.

## Возможности

- LuCI: **Services → Site_Checker**.
- Проверка HTTP/HTTPS через сетевую конфигурацию роутера: DNS, маршрутизацию и действующие правила.
- Отображение статуса, задержки и HTTP-кода.
- Редактирование списка до 30 URL.
- Автообновление каждые 60 секунд выключено по умолчанию. Чтобы включить или выключить его, измени чекбокс и нажми **«Сохранить параметр»**. Выбор сохраняется в конфигурации OpenWrt.

## Поддерживаемые версии OpenWrt

- **OpenWrt 24.x** — установщик использует `opkg`.
- **OpenWrt 25.x** — установщик использует `apk`.

Установщик автоматически выбирает пакетный менеджер и устанавливает необходимые зависимости. Совместимость зависит от конкретной сборки OpenWrt и состава LuCI.

## Установка

Выполни по SSH от `root`:

```sh
wget -O /tmp/site-checker-install.sh 'https://cdn.jsdelivr.net/gh/TMN88/Site_Checker@b180e8fdd6ee29c9ba5025530098e7cd33c42b2c/install.sh' && sh /tmp/site-checker-install.sh
```

После установки открой **LuCI → Services → Site_Checker**.

## Удаление

Если приложение установлено этим установщиком:

```sh
sh /tmp/site-checker-install.sh --uninstall
```

Конфигурация сайтов в `/etc/config/sitecheck` сохраняется.

## Замечания

- Недоступность сайта не обязательно означает блокировку: возможны проблемы DNS, TLS, маршрута, firewall или самого сервера.
- Проверка выполняется с роутера и не гарантирует, что трафик клиентов проходит точно по тому же пути.
