# Site_Checker для OpenWrt 24.x и 25.x

LuCI-панель для проверки доступности сайтов непосредственно с роутера OpenWrt.

## Возможности

- LuCI: **Services → Site_Checker**.
- Первая таблица: стандартная проверка HTTP/HTTPS с текущей конфигурацией роутера.
- Вторая таблица использует механизм из вкладки «Система» Zapret Manager: тот же список основных URL, обновляемый список доменов из `suite.v2.json`, параллельные запросы `curl`, следование редиректам, диапазон байтов `0–65535`, таймауты и User-Agent. Это адаптация блоков `_test_prepare_urls()` и `_si_sites()` из [ZapretManager_LuCI.sh](https://github.com/StressOzz/Zapret-Manager/blob/721c5c5367cc277007e7f60bb2f13b475e68d295/ZapretManager_LuCI.sh); сам Zapret и другие VPN-компоненты не устанавливаются.
- Отображение статуса, задержки и HTTP-кода в обеих таблицах.
- Настройка первой таблицы через чекбоксы: можно отключать существующие сайты, новые через интерфейс не добавляются.
- Настройка второй таблицы через чекбоксы для фиксированного списка из 16 сайтов; выбор сохраняется в браузере.
- Отдельные переключатели включения каждой из двух проверок.
- Автообновление первой таблицы каждые 60 секунд выключено по умолчанию.

**Важно:** успешный HTTP-запрос не гарантирует, что YouTube полностью воспроизводит видео; ошибка запроса не доказывает блокировку. Проверка выполняется с роутера и может отличаться от доступа клиентских устройств.

## Поддерживаемые версии OpenWrt

- **OpenWrt 24.10.x** — установщик использует `opkg`.
- **OpenWrt 25.12.x** — установщик использует `apk`.

Установщик проверяет и при необходимости устанавливает `luci-lua-runtime` вместе с зависимостями через штатный пакетный менеджер. Он нужен, потому что интерфейс приложения пока использует Lua-контроллер LuCI. Устанавливаются пакеты из настроенных на роутере feeds; не смешивайте feeds разных выпусков OpenWrt.

Совместимость с кастомными сборками, нестандартными feeds и каждой архитектурой отдельно не подтверждена. Если в feeds конкретной сборки нет `luci-lua-runtime`, установщик остановится с сообщением об ошибке, а не будет автоматически менять версию LuCI.

## Установка

Выполни по SSH от `root`:

```sh
wget -O /tmp/site-checker-install.sh 'https://cdn.jsdelivr.net/gh/TMN88/Site_Checker@d4f19865f451f47c3355a31b17fade8ddd326950/install.sh' && sh /tmp/site-checker-install.sh
```

После установки открой **LuCI → Services → Site_Checker**.

## Удаление

```sh
sh /tmp/site-checker-install.sh --uninstall
```

Конфигурация в `/etc/config/sitecheck` сохраняется.
